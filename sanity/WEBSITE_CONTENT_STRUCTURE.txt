Source: src/data/demoProjects.js
This file lists the 12 categories and 18 projects defined in src/data/demoProjects.js. These are sample concepts and demo imagery, not confirmation of actual completed business projects. Replace descriptions, wood details, and image uploads with accurate business information before publishing.

How the current code uses this data:
  - It uses the 18 demo projects when Sanity is not configured, fetch fails, or Sanity returns no projects.
  - If Sanity returns projects, those projects replace the demo projects on the site.
  - The 12 demo categories are merged with Sanity categories. A Sanity category with the same slug replaces that demo category.
  - This file can list only code-defined demo data. It cannot list additional documents stored in the Sanity project.

In Sanity, create all Category documents first. Then create each Project and select the referenced Category. The Category Type shown below is the selected Category's type; it is not a Project field. Sanity image fields require uploading image files; the website demo image URLs are not Sanity uploads.
